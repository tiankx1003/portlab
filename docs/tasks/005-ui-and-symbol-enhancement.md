# 005 — UI 优化与标的信息增强

## 目标

针对定投回测页面做三处优化：盈亏配色适配 A 股习惯、标的输入增强（名称展示 + 市场自动识别）、导航栏布局优化。

## 依赖

- [004 — 联调、收尾与文档](./004-integration-and-release.md)

## 修改项

### 1. 盈亏颜色适配 A 股习惯

当前配色为国际市场惯例（绿涨红跌），需反转为 A 股惯例：

- **红色 = 盈利**（当前误用绿色 `#3ba272`）
- **绿色 = 亏损**（当前误用红色 `#ee6666`）

涉及文件：

- `frontend/src/components/DcaChart.vue`
  - 盈亏柱状条 `itemStyle.color`：盈利改为红色系 `#ee6666`，亏损改为绿色系 `#3ba272`
- `frontend/src/views/Backtest.vue`
  - `pnlColor()` 函数：`n >= 0` 返回红色系，`n < 0` 返回绿色系
- 所有涉及盈亏颜色展示的位置统一调整

### 2. 标的信息增强

#### 2a. 图表标题展示标的名称

当前图表标题固定为「回测结果」，需改为展示标的代码 + 名称，如：

```
510300 — 沪深300ETF · 回测结果
```

- 后端 `/api/backtest/dca/{task_id}/chart` 或 `/summary` 返回中需包含标的名称
- 若后端已有数据（`raw_price_daily` 表或搜索接口），直接复用
- 前端 `ChartData` / `SummaryData` 类型新增 `symbol_name` 字段

#### 2b. 标的输入框自动识别市场

用户输入纯数字代码时，自动识别并补全市场前缀：

| 输入 | 识别规则 | 补全结果 |
|------|----------|----------|
| `000001` | 00/30 开头 → 深市 | `SZ000001` |
| `600519` | 60 开头 → 沪市 | `SH600519` |
| `510300` | 51/52 开头 → 沪市 ETF | `SH510300` |
| `159915` | 15/16 开头 → 深市 ETF | `SZ159915` |
| `688xxx` | 科创板 → 沪市 | `SH688xxx` |
| `300xxx` | 创业板 → 深市 | `SZ300xxx` |

- 前端输入框 `onSymbolInput` / `runBacktest` 中做自动补全
- 补全后在输入框中以提示文字展示完整代码（如输入 `000001`，旁边灰色提示 `SZ000001 平安银行`）
- 后端需兼容带/不带市场前缀的代码查询

### 3. 导航栏布局优化

当前 `App.vue` 导航栏中「首页」「定投回测」链接之间缺少间距，视觉上拥挤。

优化方案：

- 导航链接增加合理间距（`gap: 16px` 或每个链接加 `padding: 0 12px`）
- 激活态增加底部高亮条（`border-bottom: 2px solid` 主色），替代当前仅加粗
- 参考 Arco Design / Ant Design 风格，导航项 hover 有浅色背景过渡
- 品牌名与导航之间增加分隔感

涉及文件：

- `frontend/src/App.vue`（template + style）

- [ ] 图表标题正确显示标的代码 + 名称
- [ ] 输入纯数字代码后自动识别市场并补全 SZ/SH 前缀
