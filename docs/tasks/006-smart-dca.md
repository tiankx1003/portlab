# 006 — 智能定投（均线定投策略）

## 目标

在现有普通定投回测基础上，新增可选的「智能定投」模式。智能定投基于标的指数与 250 日均线的偏离程度，动态调整每期投入金额——低位多投、高位少投，克服人性弱点。

## 依赖

- [005 — UI 优化与标的信息增强](./005-ui-and-symbol-enhancement.md)

## 策略原理

### 核心公式

```
实际定投金额 = 设定每期金额 × 实际扣款率
```

### 参考基准

以标的对应指数的 **250 日均线**（MA250）为基准，计算 T-1 日收盘价相对均线的偏离度：

```
偏离度 X = (T-1日收盘价 - MA250) / MA250 × 100%
```

### 扣款率表

**高位少投（收盘价 ≥ MA250）：**

| 偏离度 X | 扣款率 |
|----------|--------|
| 0% ≤ X < 2% | 100% |
| 2% ≤ X < 4% | 90% |
| 4% ≤ X < 6% | 80% |
| 6% ≤ X < 8% | 70% |
| 8% ≤ X < 10% | 60% |
| X ≥ 10% | 50% |

**低位多投（收盘价 < MA250）：**

| 偏离度 X | 扣款率 |
|----------|--------|
| -2% ≤ X < 0% | 100% |
| -4% ≤ X < -2% | 110% |
| -6% ≤ X < -4% | 120% |
| -8% ≤ X < -6% | 130% |
| -10% ≤ X < -8% | 140% |
| -12% ≤ X < -10% | 150% |
| -14% ≤ X < -12% | 160% |
| -16% ≤ X < -14% | 170% |
| -18% ≤ X < -16% | 180% |
| -20% ≤ X < -18% | 190% |
| X < -20% | 200% |

> 规律：高位每偏离 2% 扣款率降 10%（下限 50%）；低位每偏离 2% 扣款率升 10%（上限 200%）。

## 交付物

### 1. 后端 — MA250 数据计算

- 新增 250 日均线计算逻辑，基于 `raw_price_daily` 表计算每个交易日的 MA250
- MA250 数据可存入 `calc_ma250` 表，或在回测时实时计算（数据量不大，实时计算也可接受）
- 偏离度计算：需要获取定投日 T-1 日的收盘价和 MA250

### 2. 后端 — 智能定投计算引擎

- `app/services/compute/dca.py` 扩展，支持 `mode` 参数：
  - `normal`（普通定投，现有逻辑）
  - `smart`（智能定投）
- 智能模式下，每个定投日：
  1. 获取 T-1 日收盘价与 MA250
  2. 计算偏离度 X
  3. 查扣款率表得到实际扣款率
  4. 实际投入 = 设定金额 × 扣款率
  5. 买入份额 = 实际投入 / 当日收盘价
- 逐日计算逻辑（市值、成本、盈亏、收益率）与普通模式相同
- `calc_dca_backtest` 表新增字段：`deduction_rate`（扣款率）、`actual_amount`（实际投入金额）

### 3. 后端 — API 扩展

`POST /api/backtest/dca` 请求体新增字段：

```json
{
  "mode": "smart",          // "normal"（默认）| "smart"
  "ma_period": 250          // 均线周期，默认 250
}
```

- `mode` 为可选字段，缺省时走普通定投逻辑
- 图表数据接口 `/chart` 和汇总接口 `/summary` 返回中新增：
  - `deduction_rates[]`：每个定投日的扣款率
  - `actual_amounts[]`：每个定投日的实际投入金额

### 4. 前端 — 表单扩展

定投回测参数表单新增：

- **定投模式** 切换：普通定投 / 智能定投（单选或开关）
- 选择智能定投时，可展开显示扣款率表格供参考
- 均线周期默认 250，高级设置中可调

### 5. 前端 — 图表增强

- 盈亏柱状条：智能定投模式下，定投日的柱状条宽度/颜色可反映实际投入金额大小
- tooltip 中增加显示：扣款率、实际投入金额
- 可选：图表中叠加 MA250 参考线

## 数据模型变更

### `calc_dca_backtest` 表新增字段

| 字段 | 类型 | 说明 |
|------|------|------|
| deduction_rate | DECIMAL(5,4) | 扣款率（如 1.0000 = 100%，1.1000 = 110%） |
| actual_amount | DECIMAL(16,2) | 当期实际投入金额（智能定投下浮动） |

## 验收标准

- [ ] 选择「智能定投」模式，回测结果中各定投日金额根据偏离度正确浮动
- [ ] 扣款率与表格对照：高位少投最低 50%，低位多投最高 200%
- [ ] 普通定投模式不受影响（回归测试）
- [ ] 图表 tooltip 显示扣款率和实际投入金额
- [ ] MA250 计算正确（取定投日前最近 250 个交易日的均价）
- [ ] 前端切换普通/智能定投时表单平滑切换
