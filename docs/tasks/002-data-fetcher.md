# 002 — 数据拉取模块

## 目标

实现标的行情数据拉取，写入 `raw_price_daily` 表，为后续回测计算提供数据基础。

## 依赖

- [001 — 项目基础设施搭建](./001-project-infrastructure.md)

## 交付物

### 1. 数据源接入

- 推荐使用 AkShare（开源免费，覆盖基金/股票/指数）
- 封装 `DataFetcher` 基类，支持后续扩展多数据源
- 实现至少一个具体 Fetcher（如 `AkShareFetcher`）

### 2. 拉取功能

- 按标的代码 + 日期范围拉取日线行情
- 字段：日期、开盘价、收盘价、最高价、最低价、成交量
- 写入 `raw_price_daily` 表，支持增量更新（避免重复插入）

### 3. 数据源配置

- 数据源类型、API Key（如需）等通过环境变量或配置文件管理
- 支持后续扩展多数据源切换

### 4. 数据拉取 API

- `POST /api/data/fetch` — 手动触发数据拉取（参数：标的代码、起始日期、结束日期）

## 验收标准

- [ ] 输入一个真实标的代码（如 `000001` 沪深300指数），成功拉取数据并入库
- [ ] 重复拉取不会产生重复数据
- [ ] 拉取失败时有明确的错误信息返回
