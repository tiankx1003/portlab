## Part A：定投回测计算引擎

### 投资日历生成

- 按定投频率（weekly/monthly）生成投资日期序列
- weekly：每周固定星期几投入（默认周三，可配置）
- monthly：每月固定日投入（默认 15 日，可配置）
- 若投入日非交易日，顺延至下一个交易日

### 逐日计算

每个交易日计算以下指标：

| 指标 | 公式 |
|------|------|
| 当日是否投入 | 布尔，是否为定投日 |
| 当日买入份额 | 投入金额 / 当日收盘价 |
| 累计份额 | Σ 历史买入份额 |
| 累计投入成本 | Σ 历史投入金额 |
| 当前市值 | 累计份额 × 当日收盘价 |
| 累计盈亏 | 市值 - 成本 |
| 收益率 | 盈亏 / 成本 × 100% |

### 汇总指标

| 指标 | 说明 |
|------|------|
| 累计投入 | 总投入金额 |
| 最终市值 | 最终权益市值 |
| 累计收益 | 绝对收益金额 |
| 累计收益率 | 总收益率 |
| 年化收益率 | 折算年化 |
| 最大回撤 | 区间内最大回撤 |
| 定投期数 | 总投资次数 |

### 交付物

- `app/services/compute/dca.py`：定投回测计算引擎
- 从 `raw_price_daily` 读取行情数据
- 计算结果写入 `calc_dca_backtest` 表（逐日数据）
- 汇总指标写入 `result_dca_summary` 表

### 数据模型

- `calc_dca_backtest`：回测任务 ID、日期、是否投入日、买入份额、累计份额、累计成本、当日市值、盈亏、收益率
- `result_dca_summary`：回测任务 ID、标的代码、定投参数、各项汇总指标

### 验收标准（计算引擎）

- [ ] 对一个已有数据的标的执行回测，逐日计算结果正确（手动抽查验证）
- [ ] 汇总指标计算正确（年化收益率、最大回撤逻辑无误）
- [ ] 计算结果成功写入 calc 和 result 表
- [ ] 相同参数重复执行不会产生重复数据

## Part B：回测 API 接口

### 1. 创建回测任务

```
POST /api/backtest/dca
```

请求体：
```json
{
  "symbol": "510300",
  "frequency": "weekly",
  "amount": 1000,
  "start_date": "2023-01-01",
  "end_date": "2024-01-01",
  "invest_day": 2
}
```

- `frequency`: `weekly`（invest_day 为 0-6，周一到周日）/ `monthly`（invest_day 为 1-28）
- 自动检查数据是否已拉取，若缺失则先触发拉取
- 返回 `task_id`

响应：
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "dca_20240101_510300_abc123"
  }
}
```

### 2. 获取回测图表数据

```
GET /api/backtest/dca/{task_id}/chart
```

返回前端 ECharts 直接消费的数据格式：

```json
{
  "code": 0,
  "data": {
    "dates": ["2023-01-03", "2023-01-04", ...],
    "market_value": [1000.0, 1005.3, ...],
    "total_cost": [1000.0, 1000.0, ...],
    "pnl": [0.0, 5.3, ...],
    "return_rate": [0.0, 0.53, ...],
    "invest_days": [true, false, ...]
  }
}
```

### 3. 获取回测汇总指标

```
GET /api/backtest/dca/{task_id}/summary
```

```json
{
  "code": 0,
  "data": {
    "total_invested": 52000.00,
    "final_value": 54300.50,
    "total_pnl": 2300.50,
    "total_return_rate": 4.42,
    "annualized_return": 4.42,
    "max_drawdown": 8.15,
    "invest_count": 52
  }
}
```

### 4. 标的搜索

```
GET /api/symbols/search?q=沪深300
```

返回标的列表（代码、名称、类型）。

### 验收标准（API）

- [ ] 所有接口返回统一 ApiResponse 格式
- [ ] Swagger UI (`/docs`) 可正常查看和测试所有接口
- [ ] 图表数据接口返回格式可直接被 ECharts 消费
- [ ] 参数校验完善（金额>0、日期合法、invest_day 在合法范围等）

## Part C：定投回测前端页面

### 1. 参数表单

- 标的选择：支持搜索（调用 `/api/symbols/search`），下拉选择
- 定投频率：单选（每周 / 每月）
- 投资日：根据频率动态展示（weekly → 周一至周日，monthly → 1-28 日）
- 每期金额：数字输入，最小 100，步长 100
- 日期范围：起始日期 + 结束日期（默认至今）
- 「开始回测」按钮

### 2. 双轴组合图表（ECharts）

布局：

```
┌────────────────────────────────────────┐
│              回测结果图表               │
│  ┌─ 左纵轴：金额（元）                  │
│  │  ── 市值曲线（主色）                 │
│  │  ── 成本曲线（灰色虚线）             │
│  │  ▎ 盈亏柱状条（盈绿/亏红）           │
│  │                                      │
│  ├─ 右纵轴：收益率（%）                 │
│  │  ── 收益率曲线（橙/金）              │
│  └──────────────────────────────────    │
│           横轴：时间                    │
└────────────────────────────────────────┘
```

- 左纵轴 + 右纵轴，双 Y 轴
- 横轴：时间（交易日）
- 市值曲线：左轴，主线
- 成本曲线：左轴，灰色虚线参考
- 盈亏柱状条：左轴，每个数据点位置，正值绿色向上、负值红色向下
- 收益率曲线：右轴，不同颜色折线
- tooltip 联动，hover 显示当日详细数据
- 支持 legend 开关各系列

### 3. 指标卡片

图表上方展示关键指标卡片：

- 累计投入
- 当前市值
- 累计收益（带颜色）
- 累计收益率（带颜色）
- 年化收益率
- 最大回撤
- 定投期数

### 4. 响应式布局

- 桌面优先，支持窗口缩放
- 图表自适应容器宽度
